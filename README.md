# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심) |
| 플레이 시간 | 1회 클리어 약 15분 (한 번도 죽지 않았을 때 기준, 방 10개) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함. 존재는 1명이 맵 전체를 순찰함
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께, 맵 전체에 4곳)
5. **방 이동** — 출입구를 지나 다음 방으로. 고양이 혼자 먼저 갈 수도 있음
6. **열쇠와 잠긴 문** — 열쇠를 찾아 잠긴 문을 열고 앞으로 나아감 (고양이·주인은 막히고 존재는 통과)
7. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |
| S / ↓ | 숨을 곳에서 숨기 / 나오기 |
| W / ↑ | 문 앞에서 문 열기 (맞는 열쇠가 있을 때) |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.11.05 (목) — 열쇠·잠긴 문 + 존재 순찰 + 10개 방 구성 초안

**결정한 것**
- 열쇠와 잠긴 문을 넣는다 (스토리가 빠진 대신 탈출 목표를 만듦)
- 존재는 **1명**이 맵 전체를 돌아다닌다
- 숨을 곳은 방 10개에 **4곳 정도**
- 방 높이는 고정하고, **가로 길이는 방마다 달라도 됨**

**10개 방 구성표 (초안)**
| 방 | 폭 | X 범위 | 내용 |
| --- | --- | --- | --- |
| 1 시작 | 17 | -8 ~ 9 | 안전한 방 (존재 안 옴) |
| 2 대기실 | 17 | 9 ~ 26 | 숨을 곳 ① 박스 |
| 3 긴 복도 | 25 | 26 ~ 51 | 열쇠 A (높은 곳, 점프로) |
| 4 진료실 | 12 | 51 ~ 63 | 숨을 곳 ② 책상 / 잠긴 문 4→5 (열쇠 A) |
| 5 병실 | 17 | 63 ~ 80 | |
| 6 창고 | 14 | 80 ~ 94 | 열쇠 B |
| 7 긴 복도 | 22 | 94 ~ 116 | 숨을 곳 ③ 캐비닛 / 잠긴 문 7→8 (열쇠 B) |
| 8 작은 방 | 12 | 116 ~ 128 | |
| 9 병실 | 17 | 128 ~ 145 | 숨을 곳 ④ 침대 / 열쇠 C |
| 10 출구 | 14 | 145 ~ 159 | 잠긴 탈출문 (열쇠 C) |

**열쇠·잠긴 문**
- `KeyItem`: 고양이가 닿으면 열쇠를 줍고 "녹슨 열쇠 획득" 메시지 표시
- `KeyInventory`: 주운 열쇠 목록. 게임을 다시 시작하면 비워짐
- `LockedDoor`: 고양이가 가까이 가면 "W / ↑ 문 열기" 안내 → 맞는 열쇠가 있으면 문이 사라지고 계속 열린 상태로 남음, 없으면 "잠겨 있다 (열쇠 이름 필요)"
  - 열쇠는 문을 열면 사라짐 (`Consume Key`를 끄면 남아서 문 여러 개를 열 수 있음)
  - 문은 Ground 레이어로 자동 설정 → 주인도 문 앞에서 멈춤. 존재(Kinematic)는 그냥 통과
  - 충돌 높이를 6으로 높게 잡아 점프로 넘지 못하게 함
  - `On Opened` 이벤트를 남겨 둠 → 나중에 탈출문에 엔딩 연결
- `HintUI`: 안내를 출처별로 보관하도록 바꿔서 숨기 안내와 문 안내가 서로 지우지 않고 함께 표시됨
- 잠긴 문·열쇠 그림을 Python으로 직접 제작: 문은 출입구 기둥의 빈 공간(46×228px)에 딱 맞는 나무판자 문 + 쇠띠 + 자물쇠, 열쇠는 34×16px 황동 열쇠

**존재 순찰**
- `PresenceAI`에 순찰 상태(`Patrolling`) 추가: 순찰 지점(Patrol Points)을 순서대로 천천히 기어 다니고, 지점에 도착하면 잠깐 멈춤 (끝에 가면 되돌아옴)
- 고양이를 놓치면 원래 자리로 돌아가지 않고 가장 가까운 순찰 지점부터 다시 순찰
- 순찰 지점을 비워두면 예전처럼 제자리에 숨어 있음
- Scene 창에서 존재를 선택하면 순찰 경로가 보라색 선으로 보임

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 숨기 안내가 매 프레임 안내 문구를 지워서 문 안내가 표시되지 않음 | HintUI가 안내를 출처(숨기, 문)별로 따로 보관하고 함께 보여주도록 변경 |
| 주인은 Ground 레이어만 벽으로 인식해서 문을 통과하려 함 | 잠긴 문이 시작할 때 스스로 Ground 레이어로 바뀌게 함 |
| 다시 시작해도 주운 열쇠가 남을 수 있음 (static 목록) | 씬을 다시 불러올 때 열쇠 목록을 비우게 함 |

**보완할 점 (나중에)**
- **오늘 만든 열쇠·문·순찰은 아직 테스트 전** → 1번→2번 방 문에 임시로 달아 테스트 (열쇠 없이 막힘, 열쇠 획득, 문 열기, 주인이 문 앞에서 멈춤, 존재 순찰·포기 후 순찰 복귀)
- 존재가 맵 전체를 순찰하므로, 주인을 순찰 길에 세워 두면 지나가던 존재에게 잡힘 → 긴장 요소로 둘지, 순찰 중에는 주인을 못 잡게 할지 테스트 후 결정
- 순찰 거리가 길어(2~10번 방) 존재가 한 바퀴 도는 데 오래 걸림 → 순찰 속도·구간 조정
- 열쇠 크기가 작게 보일 수 있음 → Visual Scale 조정
- 방 3~10 배치. 배경은 17칸 폭 기준 → 12~14칸 방은 기존 배경을 잘라 쓰고, 22~25칸 방은 넓은 배경 새로 생성
- 2번 방의 책상(숨을 곳)은 4번 방으로 이동 예정
- 탈출문 엔딩 연결 (`On Opened` → 엔딩 화면)
- 출입구 기둥이 단순함 → 필요하면 디테일 추가
- 발표용: 플레이 영상을 1~2분으로 편집, PPT 5장 구성, AI 활용에서 흥미로웠던 점 조사
- 고양이 크기: 주인 허벅지 높이까지 와서 조금 커 보임 → 필요하면 Visual Scale 0.8 정도로 조정
- 숨기 밸런스: 존재 바로 앞에서도 숨을 수 있어 너무 쉬울 수 있음 → 방 제작 후 테스트하며 조정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
