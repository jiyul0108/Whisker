# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심, 조사·퍼즐) |
| 플레이 시간 | 1회 클리어 약 15분 목표 (개발자 기준 약 5분 → 설문으로 실제 시간 측정 중) |
| 맵 | 폐병원 방 10개, 1층·지하·2층 (계단으로 이동) |
| 언어 | 영어(기본) / 한국어 — 설정에서 바꿈 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL, itch.io 공개 (Public, 11/10) — 플레이 테스트 설문 진행 중 |
| 개발 | 1인 개발 |

## 맵 구성

```
 2층   [10 수술실][9 병실(어두움)][8 진료실 ⬇]
                                       ↕  (전자 잠금 철문: 전기가 들어오면 열림)
 1층   [1 시작][2 대기실][3 복도][4 계단실 ⬇ …소화기함… ⬆][5 로비·정문]
                                    ↕  (자물쇠 철문: 녹슨 열쇠)
 지하                          [6 지하 복도][7 창고]   ← 둘 다 어두움, 전기가 들어오면 밝아짐
```

| 진행 | 내용 |
| --- | --- |
| 0 | 1번 방: 바닥 안내 그림(이동·점프·울기·숨기·조사·가방)을 지나 E 안내 아래의 **주인**을 E로 부름. 주인과 함께여야 2번 방으로 넘어갈 수 있고, 둘 다 넘어가면 문이 끼익 닫힘 |
| 1 | 3번 복도에 들어서면 존재가 뒷모습으로 서 있다가 다가가면 웃으며 사라짐 → 그 자리에 **쪽지**(예비 퓨즈 위치 4곳, 진짜는 "1층 대기실 벽시계 뒤") |
| 2 | 3번 복도 바닥의 **녹슨 열쇠** → 4번 계단실 지하 철문을 열고 지하로 |
| 3 | 2번 대기실 **의자**를 밀어 시계 밑에 놓고, 의자 위에서 **벽 타기** → **시계** 뒤에서 **퓨즈** |
| 4 | 7번 창고 **두꺼비집 작동하기** → 퓨즈 끼우기 (게이지 6초, 그동안 존재가 새로 나타나지 않음) → "쿵" 전기가 들어옴 → 2층 철문이 열리는 장면 → 6초 뒤 **존재가 계단으로 내려와 창고부터 훑음**. 주인과 함께 7번 창고 상자 더미에 숨기 |
| 5 | 5번 로비 안내데스크 **간호 일지** (침대 색 순서) + 9번 병실 **침대 4개** (이불 끝 꼬리표: 색 + 숫자) → 8번 진료실 **금고** 번호 **9472** → **열쇠 조각 (손잡이)** |
| 6 | 5번 로비 **화분** → **열쇠 조각 (끝)**, 4번 계단실 **소화기함** → **땜납** (순서 상관없음) |
| 7 | 10번 수술실 **수술대**에서 조각 2개 + 땜납으로 출구 열쇠 만들기 (게이지 10초) → 열쇠가 바닥에 떨어짐 |
| 8 | 열쇠를 줍고 문 쪽으로 가면 **존재가 천장에서 수술대 위로 떨어짐** → 숨을 곳 없이 끝까지 쫓아옴 |
| 9 | 1층 5번 로비 정문을 **주인과 함께** 열면 탈출 |

- 숨을 곳: 2번 박스·책상, 3번 책상, 7번 상자 더미, 8번 책상, 10번 수술대 (추격 중에는 숨을 수 없음)
- 방 규칙: **1번** 존재가 절대 들어오지 않음 / **2번** 갑자기 나타나지는 않지만 쫓아서 들어옴 / **지하(6·7번)** 깜짝 등장과 전원 이벤트만 (갑자기 나타나거나 쫓아오지 않음)
- 깜짝 등장(쫓아오지 않는 연출): 3번 복도(쪽지 위), 지하 복도, 2층 진료실, 병실 — 처음 지나갈 때 한 번씩

## 핵심 기능

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 의자 위에서 벽 타기
2. **고양이 시야** — 맵 전체가 어둡고, 고양이 눈에서 바라보는 쪽으로 원뿔 모양 빛(URP 2D Light). 숨으면 원뿔이 꺼지고 둘레만 좁게 보임
3. **존재** — 주인은 인식하지 못하는 적. 평소엔 사라져 있다가 고양이 근처에서 천천히 드러나 고양이가 있던 곳으로 기어옴. 같은 방에서 눈이 마주치면 쫓아오고(멀어지면 빨라져 화면 밖으로 놓치지 않음), 숨으면 숨은 곳 바로 앞까지 와서 노려보다 사라짐. 보는 앞에서 숨으면 들킴. 계단을 타고 층을 넘나들고, 주인의 비명을 듣고 찾아옴. 고양이나 주인이 닿으면 게임오버
4. **주인 인도** — E(울기)로 주인이 고양이 자리까지 따라오게 하거나, 걷는 중에 멈추게 함. 존재가 쫓아오면 뛰어서 따라옴. 화면 가운데 위에 주인 상태(따라오는 중 / 기다리는 중 / 숨어 있음)
5. **주인 공포도** — 처음 E로 부르기 전에는 0. 고양이와 멀어지거나 어두운 방에 있으면 오르고, 높을수록 느려짐. 가득 차면 비명을 지르고 존재가 소리를 듣고 옴. 울면 조금 진정
6. **숨기** — 박스·책상 등에 주인과 함께 숨어 존재를 따돌림. 숨어 있으면 심장 소리가 더 빨라짐
7. **조사·퍼즐** — ↑로 물건 조사 (쪽지·문서, 침대 1인칭 확대, 금고 번호, 두꺼비집, 수술대). 시간이 걸리는 작업은 게이지 표시
8. **인벤토리·설정** — Tab으로 인벤토리, ← →로 설정(소리 크기·프레임 제한·FPS 표시·전체 화면·언어), Tab으로 닫기
9. **이벤트** — 전원 이벤트, 추격 이벤트, 깜짝 등장, 1→2번 방 문 닫힘
10. **사운드** — 배경음악, 효과음 20여 개 (울음·발소리·비명·계단·기어다니는 소리·웃음소리 등)
11. **타이틀·탈출·게임오버** — 타이틀(게임 시작 / 설정), 탈출 성공 화면(플레이 시간), 잡히면 처음부터 다시 시작

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기, 주인 공포도 조금 내림) |
| ↑ | 조사하기, 계단 이용, 철문·정문 열기, 의자 위에서 벽 타기 |
| ↓ | 숨을 곳에서 숨기 / 나오기, 벽에서 내려오기 |
| Tab | 인벤토리 열기 / 닫기 (열린 상태에서 ← →로 설정과 오감) |
| Esc | 설정 열기 (웹 전체 화면에서는 전체 화면이 풀리면서 설정이 열림), 문서·침대·금고 창 닫기, 작업(게이지) 그만두기 |
| 설정 창 | ↑ ↓ 고르기, ← → 값 바꾸기 (맨 위 줄에서는 인벤토리로), Enter 선택, Tab 닫기 |
| 금고 | ← → 자리 이동, ↑ ↓ 숫자 바꾸기, 숫자 키로 바로 입력, Enter 확인 |
| R | 게임오버·탈출 화면에서 처음부터 다시 시작 |
| 타이틀 | ↑ ↓ + Enter 또는 마우스 클릭 (게임 시작 / 설정) |

### 2026.11.10 (화) — itch.io 공개, 표지 그림, 플레이 테스트 설문 배포

**itch.io 공개**
- 표지 그림 제작(`docs/images/whisker_cover.png`, 630×500): 게임에 쓰는 그림만으로 합성 — 3번 복도 배경, 겁먹은 주인, 털을 세운 고양이, 오른쪽 어둠에서 기어 오는 존재. 맵 전체를 어둡게 하고 고양이 눈에서 나온 원뿔 빛에만 존재가 비치게 해서 "고양이만 볼 수 있는 것"을 표현. 제목은 Galmuri11
- 공개 범위 결정: Restricted는 참여자마다 Download Key + itch.io 가입이 필요해서 응답률이 떨어짐 → **Public**으로 공개
- 페이지 설명(영어), 조작법, 크레딧, AI 사용 공개(그림·소리·글·코드) 작성

**플레이 테스트 설문 (Google Form)**
- 개인정보는 이름만 받고(이메일 수집 안 함), 나머지는 게임에 관한 문항으로 5문항, 약 3분
  1. 이름 (단답형, 필수)
  2. 플레이 시간 (객관식: 5분 미만 / 5~10분 / 10~15분 / 15~20분 / 20분 이상)
  3. 난이도 (1~5, 너무 쉬움 ~ 너무 어려움)
  4. 무섭고 긴장감 있었는지 (1~5, 전혀 아님 ~ 매우 그렇다)
  5. 막혔던 곳·버그·아쉬운 점·좋았던 점 (장문형, 선택)
- 설문 설명에 게임 링크, 안내 문구(PC·키보드 필요, Tab → →로 언어 변경)와 함께 배포. 목표 응답 10개 이상
