# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심, 조사·퍼즐) |
| 플레이 시간 | 1회 클리어 약 15분 목표 (한 번도 죽지 않았을 때 기준) |
| 맵 | 폐병원 방 10개, 1층·지하·2층 (계단으로 이동) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, itch.io 배포 예정) |
| 개발 | 1인 개발 |

## 맵 구성

```
 2층   [10 수술실][9 병실(어두움)][8 진료실 ⬇]
                                       ↕  (전자 잠금 철문: 전기가 들어오면 열림)
 1층   [1 시작][2 대기실][3 복도][4 계단실 ⬇ …소화기함… ⬆][5 로비·정문]
                                    ↕  (자물쇠 철문: 녹슨 열쇠)
 지하                          [6 지하 복도][7 창고]   ← 둘 다 어두움, 전기가 들어오면 밝아짐
```

| 진행 | 내용 |
| --- | --- |
| 1 | 3번 복도 손잡이 위에서 **녹슨 열쇠** (점프) → 4번 계단실 지하 철문을 열고 지하로 |
| 2 | 7번 창고 **두꺼비집** 조사 → "퓨즈가 하나 빠져 있다" |
| 3 | 2번 대기실 **의자**를 밀어 시계 밑에 놓고, 의자 위에서 **벽 타기** → **시계** 뒤에서 **퓨즈** (두꺼비집을 먼저 조사해야 나옴) |
| 4 | 두꺼비집에 퓨즈 끼우기 (게이지 6초) → "쿵" 전기가 들어옴 → 2층 철문이 열리는 장면 → **존재가 지하로 내려옴**. 6초 안에 주인과 함께 7번 창고 상자 더미에 숨기 |
| 5 | 5번 로비 안내데스크 **간호 일지** (침대 색 순서) + 9번 병실 **침대 4개** (이불 끝 꼬리표: 색 + 숫자) → 8번 진료실 **금고** 번호 **9472** → **열쇠 조각 (손잡이)** |
| 6 | 5번 로비 **화분** → **열쇠 조각 (끝)**, 4번 계단실 **소화기함** → **땜납** (순서 상관없음) |
| 7 | 10번 수술실 **수술대**에서 조각 2개 + 땜납으로 출구 열쇠 만들기 (게이지 10초) → 열쇠가 바닥에 떨어짐 |
| 8 | 열쇠를 줍고 문 쪽으로 가면 **존재가 천장에서 수술대 위로 떨어짐** → 숨을 곳 없이 끝까지 쫓아옴 |
| 9 | 1층 5번 로비 정문을 **주인과 함께** 열면 탈출 |

- 숨을 곳: 2번 박스·책상, 7번 상자 더미, 8번 책상, 10번 수술대 (추격 중에는 "숨을 곳이 없다")
- 1번 방은 존재가 오지 않는 안전한 방

## 핵심 기능

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 의자 위에서 벽 타기
2. **존재** — 주인은 인식하지 못하는 적. 계단을 타고 층을 넘나들며 맵 전체를 돌아다니다가 고양이와 눈이 마주치면 쫓아옴. 고양이나 주인이 닿으면 게임오버
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **주인 공포도** — 고양이와 멀어지거나 어두운 방에 있으면 오르고, 높을수록 주인이 느려짐. 고양이가 울면 조금 진정됨
5. **숨기** — 박스·책상 등에 숨어 존재를 따돌림. 숨어 있으면 심장 소리가 더 빨라짐
6. **조사·퍼즐** — W로 물건 조사 (문서, 침대 1인칭 확대, 금고 번호, 두꺼비집, 수술대). 시간이 걸리는 작업은 게이지 표시, Esc로 그만두기
7. **인벤토리** — 오른쪽 위에 가진 아이템, Tab으로 이름·설명 보기 (보는 동안 게임 멈춤)
8. **이벤트** — 전원 이벤트(철문이 열리는 장면 + 존재가 지하로 내려옴), 추격 이벤트(존재가 수술대 위로 떨어짐)
9. **방·층 이동** — 출입구를 지나 옆 방으로, 계단으로 다른 층으로. 주인이 가까이 있으면 계단을 함께 이동
10. **탈출 / 게임오버** — 출구 열쇠로 주인과 함께 정문을 열면 탈출 성공(플레이 시간 표시). 잡히면 처음부터 다시 시작

## 조작법

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기, 주인 공포도 조금 내림) |
| W / ↑ | 조사하기, 계단 이용, 철문·정문 열기, 의자 위에서 벽 타기 |
| S / ↓ | 숨을 곳에서 숨기 / 나오기, 벽에서 내려오기 |
| Tab | 인벤토리 열기 / 닫기 |
| Esc | 문서·침대·금고 창 닫기, 작업(게이지) 그만두기 |
| 금고 | A/D 자리 이동, W/S 숫자 바꾸기, 숫자 키로 바로 입력, Enter 확인 |
| R | 게임오버·탈출 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.11.08 (일) — 퍼즐 진행 확장 + 조사·인벤토리·주인 공포도 + 전원·추격 이벤트 + 효과음

**왜 바꿨나**
- 열쇠 3개로 문 3개를 여는 구조는 플레이 시간이 너무 짧음 → 직접 진행 구조를 새로 짬 (열쇠를 찾기만 하는 게 아니라 조사·조합·이벤트 추가)
- 녹슨 열쇠 → 두꺼비집 조사 → 시계의 퓨즈 → 전원 이벤트 → 침대 단서·금고 → 열쇠 조각·땜납 → 수술대에서 출구 열쇠 만들기 → 추격 → 탈출

**조사·퍼즐 (`Interactable.cs` 하나로 모든 조사 물건 처리)**
- 조건(진행 표시·필요 아이템) → 보상(아이템·진행 표시·메시지) → 특수 동작(문서·침대·금고·전원·만들기)
- 아이템이 없을 때 조사만 해도 진행 표시를 남김 (두꺼비집 → `FUSEBOX_CHECKED` → 그때부터 시계에서 퓨즈가 나옴)
- 시간이 걸리는 작업: **Use Gauge**를 켜면 게이지(`CraftUI`)가 다 찬 뒤 동작. 퓨즈 끼우기 6초, 열쇠 만들기 10초. 만드는 동안 고양이는 못 움직이고(존재는 계속 움직임) Esc로 그만두면 재료는 그대로
- 수술대에서 다 만들면 출구 열쇠가 위에서 "톡" 떨어지고(Reveal Object), 주워야 함
- 문서·침대·금고 창(`PopupUI`): 보는 동안 게임 멈춤. 금고는 A/D·W/S 또는 숫자 키로 입력
- 침대 4개: 1인칭 확대 그림(Gemini) 이불 끝에 꼬리표(색 띠 + 숫자)를 Python으로 그려 넣어 침대마다 다른 그림. 간호 일지 "해가 뜨는 색(노랑) → 숲(초록) → 피(빨강) → 바다(파랑)" → 9472
- 땜납은 처음 지하 공구함에 두었다가 **4번 계단실 계단 사이 소화기함**으로 옮김 (배경 그림 위치에서 X 61.46)

**의자 + 벽 타기 (`ClimbSpot.cs`, `CatOnlyProp.cs`)**
- 2번 방 배경에서 시계 밑 책상을 오른쪽으로 옮김 (OpenCV로 경계를 자연스럽게 섞음) → 그 자리에 밀 수 있는 의자를 놓음
- 의자 위에 서 있을 때만 W로 벽 타기(벽 타기 그림 4장) → 다 올라가면 시계 조사, S로 내려옴
- 주인이 의자에 걸려 따라오다 멈추는 문제 → 의자는 고양이만 부딪히게 (주인·존재와 충돌 무시, 주인의 벽 감지에서도 제외)

**인벤토리·주인 공포도**
- 오른쪽 위 아이템 칸 + Tab으로 이름·설명 (`InventoryUI`, `ItemDB`, 아이콘 6개는 Python으로 그림)
- 왼쪽 위 **주인 공포도**: 주인은 존재를 못 보므로 고양이와 멀어지거나 어두운 방에 있으면 오름. 높을수록 느려져 가장 높을 때 평소 속도의 40%, 내려가면 평소 속도. 울기로 조금 진정 (`OwnerFear`)
- 어두운 방(`Room`): 6·7번(전기가 들어오면 깜빡이다 밝아짐), 9번(계속 어두움)

**이벤트**
- 전원(`PowerEvent`): 쿵 + 화면 흔들림·번쩍임 → 카메라가 계단실로 가서 2층 전자 잠금 철문이 열리는 장면 → 6초 뒤 존재가 지하로 내려와 지하 전체를 훑고 지나감 (그동안 계단 막힘)
- 추격(`ChaseEvent`): 출구 열쇠를 가진 채 수술실 문 쪽(X 29)으로 가면 존재가 천장에서 수술대 위로 떨어짐 → 울부짖고 → 계단까지 따라오며 끝까지 추격. 추격 중에는 "숨을 곳이 없다"
- 심장 소리(`Heartbeat`): 같은 층에서 존재가 가까울수록 빨라짐. **숨어 있을 때는 존재가 멀어도 뛰고 30% 더 빨라짐**

**효과음 (ElevenLabs → Python 편집)**
- 심장(한 박자만 남김), 전기 쿵, 철문, 떨어짐, 작업 중 반복 소리 → `Assets/Audio/`, 배치 메뉴에서 자동 연결
- 반복 소리는 mp3 앞뒤 빈 구간 때문에 끊겨서 wav로 바꾸고 끝과 처음을 겹쳐 이음매 없앰

**배치 메뉴 (`WhiskerMapBuilder.cs`) 갱신**
- 의자·벽 타기·시계, 두꺼비집, 소화기함, 화분, 간호 일지, 침대 4개, 금고, 수술대·출구 열쇠, 전원·추격 이벤트, 인벤토리·팝업·게이지 화면, 주인 공포도, 심장 소리, 효과음까지 한 번에 배치
- 2층 계단 철문은 자물쇠 없이 전자 잠금(`POWER`)으로, 예전 작은 열쇠 B·출구 열쇠 C 줍기는 삭제

| 아이템 아이콘이 작고 조각 아이콘 크기가 제각각 | 72px 칸으로 키우고 아이템마다 확대 비율을 맞춤 |
