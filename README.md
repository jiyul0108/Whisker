# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심) |
| 플레이 시간 | 1회 클리어 약 15분 (한 번도 죽지 않았을 때 기준, 방 10개) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께)
5. **방 이동** — 출입구를 지나 다음 방으로. 고양이 혼자 먼저 갈 수도 있음
6. **열쇠와 잠긴 방** — 열쇠를 찾아 잠긴 방을 열고 앞으로 나아감 (검토 중)
7. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |
| S / ↓ | 숨을 곳에서 숨기 / 나오기 |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.11.04 (수) — 방향 변경(쪽지·스토리 제거) + 방 이동 + 2번 방 배경

**교수님 면담**
- 발표 시간: 수업 5분, 경진대회 10분 → 15분짜리 게임은 영상을 짧게 편집해야 함
- PPT 5장 + 첨부 영상 형식도 가능
- 발표 초점은 게임 소개보다 **AI를 활용해 만든 과정**: AI를 쓰면서 흥미로웠던 점(예: Gemini 이미지 생성, Claude Python 후처리), 후처리로 무엇이 보완·수정됐는지
- → AI 활용 기록 문서 `docs/AI_USAGE.md`를 만들어 지금까지의 과정을 날짜별로 정리 (작업할 때마다 이어서 기록)

**방향 변경: 쪽지·스토리 제거**
- 스토리 없이 탈출 중심의 공포 게임으로 변경
- `Note.cs`는 프로젝트 밖 `Archive/` 폴더로 옮겨 보관 (Unity가 읽지 않음)
- `NoteUI.cs` → **`HintUI.cs`**로 이름을 바꾸고 화면 아래 안내 문구만 남김
  - `SetHint()`: 계속 떠 있는 안내 (숨기 안내)
  - `ShowMessage()`: 잠깐 떴다 사라지는 메시지 (예: "잠겨 있다")
  - 파일 이름만 바꾸고 .meta는 그대로 옮겨서 씬의 컴포넌트·폰트 설정이 그대로 유지됨
- 고양이 조작·울기·숨기 스크립트에서 쪽지 관련 코드 제거

**방 이동**
- 방들을 가로로 이어 붙이고, `Room`(Box Collider 2D의 가로 범위 = 방 범위)으로 방마다 범위를 지정
- `CameraFollow`가 고양이가 있는 방을 찾아 카메라 범위를 자동으로 바꾸고, 방이 바뀌는 순간 바로 새 방 화면으로 넘어감
- 순간이동이 아니라 걸어서 넘어가므로 **고양이 혼자 먼저 갔다가 돌아올 수 있고**, 주인도 울음소리를 들으면 같은 출입구로 따라옴
- 출입구 기둥 배치 규칙: 출구 기둥 X = 방 오른쪽 끝 − 0.28, 입구 기둥 X = 방 왼쪽 끝 + 0.28 (Flip X), Order in Layer 3

**2번 방 배경 (Gemini)**
- 1번 방과 같은 프롬프트 구조에 장면만 바꿈: 대기 의자 줄, 쌓인 상자, 책상, 판자로 막힌 창문, 고장 난 시계
- 1번 방 배경을 **스타일 참고로 첨부** → 벽지·색감·바닥판·천장 높이가 1번 방과 똑같이 나옴
- 후처리: 1번 방과 같은 크기(1700×592)로 맞추고, 바닥판 윗선을 측정해 기준점 설정 (2번 방은 바닥선이 1.5px 낮게 그려져 있어 따로 맞춤)
- 배경에 그려진 박스 더미·책상 위치에 Hide Spot(박스, 책상)을 겹쳐 배치하고, 숨을 곳의 임시 그림은 끔

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 존재가 1번 방 가운데를 막아 출입구로 못 지나감 | 1번 방은 존재가 없는 시작 방 → 존재를 2번 방(x = 20)으로 이동 |
| 출입구 기둥이 방 끝에서 떨어져 있어 옆에 벽 조각이 남아 보임 | 기둥 바깥면이 방 경계에 딱 맞게 위치 조정 |
| 고양이가 출입구를 통과하지 않고 기둥 뒤로 숨는 것처럼 보임 | 기둥을 캐릭터보다 뒤(Order 20 → 3)에 그려서, 어두운 출입구 앞을 지나가게 함 |

**보완할 점 (나중에)**
- **열쇠·잠긴 문을 넣을지 결정** (스토리가 빠져 목표를 만들기 위해 넣는 쪽을 검토 중)
- 방 10개 구성 다시 정하기 (스토리 없이, 존재 배치·숨을 곳·턱 위주로)
- 나머지 방 배경 8개 (같은 프롬프트 + 1번 방 그림을 스타일 참고로 첨부)
- 출입구 기둥이 단순함 → 필요하면 디테일 추가
- 발표용: 플레이 영상을 1~2분으로 편집, PPT 5장 구성, AI 활용에서 흥미로웠던 점 조사
- 고양이 크기: 주인 허벅지 높이까지 와서 조금 커 보임 → 필요하면 Visual Scale 0.8 정도로 조정
- 숨기 밸런스: 존재 바로 앞에서도 숨을 수 있어 너무 쉬울 수 있음 → 방 제작 후 테스트하며 조정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
