# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심) |
| 플레이 시간 | 1회 클리어 약 15분 목표 (한 번도 죽지 않았을 때 기준) |
| 맵 | 폐병원 방 10개, 1층·지하·2층 (계단으로 이동) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 맵 구성

```
 2층   [10 수술실][9 병실][8 진료실 ⬇]
                                 ↕  (잠긴 철문: 작은 열쇠 B)
 1층   [1 시작][2 대기실][3 복도][4 계단실 ⬇ ……… ⬆][5 로비·정문]
                                    ↕  (잠긴 철문: 녹슨 열쇠 A)
 지하                          [6 지하 복도 ⬆][7 창고]
```

| 진행 | 내용 |
| --- | --- |
| 1 | 3번 복도 손잡이 위에서 **녹슨 열쇠 A** (점프) |
| 2 | 4번 계단실 지하 계단의 철문을 열고 지하로 |
| 3 | 7번 창고 선반에서 **작은 열쇠 B** (점프) |
| 4 | 1층으로 올라와 2층 계단의 철문을 열고 2층으로 |
| 5 | 10번 수술실 기구 카트 위에서 **출구 열쇠 C** (점프) |
| 6 | 1층 5번 로비 정문을 **주인과 함께** 열면 탈출 |

- 숨을 곳: 2번 박스·책상, 7번 상자 더미, 8번 책상, 10번 수술대
- 1번 방은 존재가 오지 않는 안전한 방

## 핵심 기능

1. **고양이 이동 및 탐색** — 좌우 이동, 점프 (높은 곳의 열쇠 줍기)
2. **존재** — 주인은 인식하지 못하는 적. 1명이 계단을 타고 층을 넘나들며 맵 전체를 알아서 돌아다니다가 고양이와 눈이 마주치면 쫓아옴. 고양이나 주인이 닿으면 게임오버
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께)
5. **방·층 이동** — 출입구를 지나 옆 방으로, 계단으로 다른 층으로. 주인이 가까이 있으면 계단을 함께 이동
6. **열쇠와 잠긴 철문** — 열쇠로 철문을 열면 자물쇠가 떨어지고 문이 열리는 동작 후 계단을 이용 가능
7. **탈출 / 게임오버** — 출구 열쇠로 주인과 함께 정문을 열면 탈출 성공(플레이 시간 표시). 잡히면 처음부터 다시 시작

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |

## 개발 기록

### 2026.11.07 (토) — 방 10개 완성 + 1층·지하·2층 + 계단 + 탈출 엔딩

**맵 구조 변경: 한 줄 → 3개 층**
- 방을 가로로만 잇지 않고 1층·지하·2층으로 나눔 (1층 5개, 지하 2개, 2층 3개)
- 층마다 높이를 20칸씩 떨어뜨려 배치 (1층 바닥 -2.5, 지하 -22.5, 2층 17.5)
- 4번 계단실의 계단 입구와 지하 6번·2층 8번의 계단 입구가 위아래로 겹치도록 방 X 위치를 맞춤

**배경 (Gemini 8장 + Python 후처리)**
- 3번 복도: 같은 크기로 받아 가운데 빈 벽을 이어 붙여 25칸 폭으로 늘림 (이음매가 티 나지 않게 밝기 맞춤 + 겹쳐 섞기)
- 4~10번: 계단실, 로비, 지하 복도, 창고, 진료실, 병실, 수술실
  - 4·6번은 오른쪽 아래 바닥 띠가 비어 있음 (프롬프트의 "오른쪽 아래 비워두기"를 바닥까지 비움) → 왼쪽 바닥을 복사해 메움
  - 지하 6번·2층 8번에는 도착할 계단 입구가 없음 → 4번 계단실 그림의 계단 입구를 잘라 붙이고, "2F" 판의 "2"를 지우고 "B1" 판의 "1"을 옮겨 **"1F" 표지판**을 만듦
  - 8번 진료실은 가구가 실제의 2~3배로 커서 크기를 지정한 프롬프트로 다시 생성 (Python으로 가구만 줄이는 방법은 빈 벽을 메운 자국이 티 나서 사용 안 함)
- 고양이 발 위치: 2층 진료실처럼 바닥판 가운데쯤 서는 게 자연스러워서, 모든 방을 "바닥판 윗선~검은 부분의 56% 지점"으로 기준점을 다시 맞춤

**계단 (`Stairs.cs`)**
- 계단 앞에서 W / ↑ → 화면이 어두워졌다가 연결된 층의 계단 앞으로 이동
- 주인이 2.5칸 안에 있으면 함께 이동, 멀면 "주인은 따라오지 못했다"
- 잠긴 계단은 **철문**으로 막혀 있음 → 맞는 열쇠로 W를 누르면 덜컹 → 자물쇠가 떨어짐 → 문이 안쪽으로 열리는 동작 → 다시 W로 계단 이용
- 철문 그림은 계단실 출입구 크기(168×262px)와 색에 맞춰 Python으로 제작 (처음 나무판자+쇠사슬 문 → 요청으로 병원 철문으로 변경)

**층에 맞춘 코드 수정**
- `Room`: 가로뿐 아니라 세로 범위로도 방을 판별 (같은 X에 층이 여러 개)
- `CameraFollow`: 고양이가 있는 방의 높이로 카메라 높이를 맞춤
- `OwnerController`: 고양이가 혼자 다른 층으로 가면 따라가기를 멈춤, 계단 함께 이동
- `PresenceAI`: 목적지 방이 다른 층이면 이 층의 계단으로 가서 층을 옮긴 뒤 계속 돌아다님 (잠긴 문과 상관없이 통과)

**탈출 엔딩**
- `GameManager.GameClear()`: 화면 암전 후 `ESCAPED` + 플레이 시간 + R로 다시 시작
- `LockedDoor` 탈출문 옵션: 출구 열쇠가 있어도 **주인이 3칸 안에 있어야** 열림 ("주인과 함께 나가야 한다")
- 5번 로비의 쇠사슬 정문 그림 위치에 판정만 배치

**방 자동 배치 메뉴 (`Assets/Editor/WhiskerMapBuilder.cs`)**
- 메뉴 **Whisker > 추가한 방 배치하기** 한 번으로 3~10번 방 범위·배경·기둥·층 바닥과 벽·계단 4개·열쇠 3개·숨을 곳·탈출문을 배치
- 다시 누르면 `Rooms_Added`를 지우고 새로 만듦. 시험용 잠긴 문(`LockedDoor_01`)은 계단 잠금으로 대신해서 삭제

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 임시 배경(1·2번 방을 잘라 만든 4~10번)을 묻지 않고 먼저 만듦 | 지우고 한 방씩 새 배경으로 진행 (임시 배경은 프로젝트 밖으로 옮김) |
| 계단으로 올라가고 내려간 층에 계단 입구 그림이 없음 | 4번 계단실 그림의 출입구를 잘라 6·8번에 합성, "1F" 표지판도 합성 |
| 존재 때문에 테스트 중 맵을 돌아다니기 어려움 | 테스트할 때는 Presence 오브젝트를 꺼서 확인 (밸런스는 나중에 조정) |
| 방 이동할 때 렉 | 존재·주인이 상태가 바뀔 때마다 찍던 로그가 쌓여 에디터가 끊김 → 확인용 로그를 `GameLog`로 바꿔 평소에는 실행되지 않게 함 |
| 8번 진료실 책상·진료 의자가 주인보다 큼 | 크기를 지정한 프롬프트로 다시 생성 |
| 고양이 발이 바닥판 윗선에 떠 보임 | 방마다 바닥판을 재서 기준점을 바닥판 가운데쯤으로 다시 설정 |
| 철문 그림이 바뀌지 않음 | 파일을 보낼 때 이전 그림이 다시 올라감 → 다시 보내고 픽셀이 같은지 확인 |

**보완할 점 (나중에)**
- 처음부터 끝까지 플레이 시간 측정 → 15분 목표에 맞춰 존재 속도·대기 시간·발견 거리 조정
- 존재가 추격 중에는 1번 방(안전한 방)까지 쫓아올 수 있음 → 필요하면 막기
- 계단을 탄 직후 존재가 바로 앞에 있으면 피할 수 없음 → 잠깐 못 잡게 할지 테스트 후 결정
- 9번 병실 침대가 많아 숨을 수 있어 보임 → 침대를 숨을 곳으로 추가할지 결정
- 10번 수술대는 실제보다 약 2배 크지만 그대로 두기로 함
