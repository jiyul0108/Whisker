# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인을 부르거나 멈추게 해서 안전한 길로 이끎
4. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀을 알아감
5. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (근처의 주인 부르기 / 멈추기) |
| W / ↑ | 쪽지 읽기 / 닫기 (Esc로도 닫기) |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.10.31 (토) — 쪽지 줍기·읽기 기능

**쪽지 시스템**
- `Note`: 쪽지 하나하나에 붙는 스크립트. Inspector에서 제목과 내용을 입력
  - 안 읽은 쪽지는 위아래로 살짝 떠다니고, 읽으면 회색으로 바뀜
  - 고양이가 닿으면(Trigger) `NoteUI`에 "근처에 쪽지 있음"을 알림
- `NoteUI`: 쪽지 화면 담당 (실행할 때 Canvas를 코드로 직접 생성)
  - 쪽지 근처에서 화면 아래에 "W / ↑ 쪽지 읽기" 안내 표시
  - W / ↑로 열면 게임 정지(`Time.timeScale = 0`) + 화면을 어둡게 하고 종이 팝업에 제목·내용 표시
  - W / ↑ / Esc로 닫으면 이어서 진행
  - 오른쪽 위에 "쪽지 읽은 수 / 전체 수" 표시 (전체 수는 씬의 쪽지 개수를 자동으로 셈)
- 쪽지를 읽는 동안 고양이 이동·점프·울기를 막음 (`CatController`, `CatMeow`에서 `NoteUI.IsReading` 확인)
- 읽기 키를 W / ↑로 정한 이유: 울기(E), 점프(Space)와 겹치지 않게
- 재시작하면 씬을 새로 불러오므로 읽은 쪽지도 처음 상태로 돌아감

**한글 폰트**
- Unity 기본 폰트에는 한글이 없어 WebGL에서 깨짐 → 무료 한글 픽셀 폰트 **Galmuri11** 추가 (OFL 1.1)
- 픽셀 그림체와 어울리는 폰트로 선택. 파일이 커서(약 5MB) 굵은 글씨용 Bold 파일은 넣지 않음

**쪽지 그림**
- Python으로 30×38px 픽셀 쪽지 그림을 임시로 제작 (접힌 모서리, 줄, 얼룩)
- 임포트 설정을 미리 맞춘 .meta 파일을 함께 만들어 넣음: Pixels Per Unit 100, Filter Point, Compression None, Pivot 발밑

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 스토리가 아직 정해지지 않아 쪽지 내용과 배경을 만들 수 없음 | 스토리와 상관없는 쪽지 기능을 먼저 만들고, 내용은 임시 글로 넣음. 배경은 스토리 확정 후로 미룸 |
| 쪽지를 읽는 동안 누른 Space가 닫은 뒤 점프로 이어질 수 있음 | 읽는 동안에는 점프 입력을 버리고, 닫기 키에서 Space를 뺌 |

**보완할 점 (나중에)**
- 스토리 확정: 폐병원(A) / 폐교(B) / 폐병원 + "고양이를 쫓아 들어감" 도입(A+B) 중 선택 → 쪽지 8개 내용, 방 구성, 배경 확정
- 배경 이미지 (스토리 확정 후 Gemini로 생성)
- 쪽지 그림은 임시 → 배경 그림체에 맞춰 교체할지 결정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재에게서 도망치는 방법(숨기, 시야 밖으로 벗어나기 등)은 스토리를 구성하면서 다시 정하기
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
