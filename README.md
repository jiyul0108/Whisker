# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인을 부르거나 멈추게 해서 안전한 길로 이끎
4. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀을 알아감
5. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 개발 기록

### 2026.10.11 (일) — 주인 웨이포인트 + 울기

**프로토타입**
- 주인(도형) 추가
  - Rigidbody 2D **Kinematic**: 중력 없이 스크립트가 정한 경로로만 이동
  - Box Collider 2D **Is Trigger**: 고양이가 주인과 부딪히지 않고 겹쳐 지나감 (추후 존재와의 접촉 감지에도 사용)
- 웨이포인트(WP1~WP4): 주인이 들르는 "정거장"을 빈 오브젝트로 배치. 방3으로 가는 좁은 통로는 주인이 통과하지 못하는 구간이라 경로를 방2까지로 설정
- `OwnerController`: 웨이포인트를 순서대로 이동하는 상태 머신
  - 대기(파랑) → 이동(초록) → 다음 지점 도착 시 다시 대기 → 마지막 지점 도착 시 탈출(노랑)
- `CatMeow`: E 키로 울기
  - 범위(4칸) 안의 주인이 대기 중이면 출발, 이동 중이면 정지
  - 범위 밖이면 반응 없음, 0.5초 쿨타임
  - 울 때 입 벌린 그림을 잠깐 표시
- 주인(키 1.6칸)이 턱 밑을 지나갈 수 있도록 턱 높이 조정

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 울 때 고양이 그림이 흐려 보임 | 울기 원본 해상도가 낮았음 → 픽셀 평균 대신 칸마다 대표 색 하나를 고르는 방식으로 전체 스프라이트 재처리 |
| 울 때 고양이가 작아짐 | 울기 그림만 Pixels Per Unit 128, 나머지는 기본값 100 → 전체 100으로 통일 |
| 스프라이트 설정이 기본값(Bilinear, 압축)이었음 | 고양이 그림 40개 전부 Filter Point, Compression None으로 통일 (검색창 `t:Texture2D`로 일괄 선택) |
| 대기 → 울기 전환 시 이질감 | 서로 다른 생성 이미지라 입뿐 아니라 몸 전체가 바뀜 → 같은 장에서 나온 울기 1번(입 다문 그림)을 평소 그림으로 사용 |

**메모**
- 모션끼리(대기 → 걷기 등) 바뀔 때도 색감·외곽선 차이가 보일 수 있음 → 애니메이션 연결 후 확인, 필요하면 색감 통일 후처리
- 고양이 스프라이트 설정 기준: Pixels Per Unit 100, Filter Point, Compression None

### 2026.10.10 (토) — 고양이 에셋 제작 + 프로토타입

**고양이 에셋 (Gemini)**
- 기준 캐릭터 생성: 대기 자세는 3/4 각도, 이동 모션은 측면
- 감정 대기 자세 2종: 평온, 경계
- 모션 8종: 걷기, 겁먹은 채 걷기, 점프, 기어가기, 벽타기(뒷모습), 숨기(실루엣 + 눈), 겁먹음, 울기
- 후처리: 초록 배경 제거, 프레임 분리, 크기 통일, 발 기준 정렬, 96px 해상도
  - 벽타기 3번 프레임은 1번 좌우 반전, 걷기 3번 프레임은 다리 명암 보정

**프로토타입**
- 고양이: Rigidbody 2D + Box Collider 2D + 마찰 0 물리 재질 (벽 달라붙음 방지)
- `CatController`: 좌우 이동, 점프, 발밑 바닥 체크 (GroundCheck + Ground 레이어)
- `CameraFollow`: 카메라가 고양이를 부드럽게 따라감
- 테스트 맵: 방 3개 연결 (넓은 통로, 좁은 통로, 계단·턱)
- 네모 도형 고양이를 스프라이트(대기 자세)로 시험 교체

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 고양이가 바닥을 뚫고 떨어짐 | 바닥·벽에 Box Collider 2D 추가 |
| 점프가 안 됨 | 바닥 오브젝트에 Ground 레이어 지정 |
| 턱에 올라가지 못함 | Jump Force 12 → 20 |
| 벽과 천장 사이 틈 | 천장 위치 조정 |
| 스프라이트 화질 저하 (48px) | 96px로 재처리 |
| 스프라이트 테두리에 초록빛 | 경계 깎기 + 초록 보정 강화 |
| 스프라이트 발이 바닥에 파묻힘 | 충돌 범위와 GroundCheck를 발바닥에 맞춤 |

**AI 이미지 생성에서 배운 점**
- 여러 모션을 한 번에 요청하면 일관성이 깨짐 → 모션 하나당 요청 한 번
- 한 장 안에서 일부 프레임만 수정하는 요청은 거의 반영되지 않음 → 좌우 반전·프레임 선택 등 후처리로 해결
- 동작 이름보다 프레임별 형태를 구체적으로 지시해야 원하는 결과가 나옴
