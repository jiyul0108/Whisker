# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인을 부르거나 멈추게 해서 안전한 길로 이끎
4. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀을 알아감
5. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 프로젝트 구조

```
Assets/
├── Art/Characters/
│   ├── Cat/Sprites/              고양이 스프라이트 (모션별 폴더)
│   ├── Owner/Sprites/            주인 스프라이트 (idle, walk, hide)
│   └── Presence/Sprites/         존재 스프라이트 시안 (idle, notice, crawl, pounce)
├── Physics/                      물리 재질 (NoFriction)
├── Scenes/Prototype/              Main 씬 (테스트 맵)
└── Scripts/
    ├── CatController.cs          고양이 이동·점프·바닥 체크
    ├── CatAnimator.cs            고양이 애니메이션 (대기·걷기·점프·착지·울기)
    ├── CatMeow.cs                울기 (주인 호출)
    ├── CameraFollow.cs           카메라 따라가기
    ├── OwnerController.cs        주인 웨이포인트 이동 상태 머신
    ├── OwnerAnimator.cs          주인 애니메이션 (대기·걷기) + 떨림
    └── PresenceAI.cs             존재 AI (시야 판정·발견·추격·덮치기·복귀)
```

## 개발 기록

### 2026.10.28 (수) — 존재 AI ①: 시야·발견·추격

**존재 AI (`PresenceAI`)**
- 상태 머신: 숨어 있음 → 발견 → 추격 → 덮치기 → (놓치면) 복귀 → 숨어 있음

| 상태 | 하는 일 | 다음 상태로 |
| --- | --- | --- |
| 숨어 있음 | 제자리 대기 (대기 그림 3장) | 고양이와 5칸 안에서 눈이 마주치면 → 발견 |
| 발견 | 1.2초 동안 발견 그림 3장 (가린 얼굴 → 충혈된 눈) | → 추격 |
| 추격 | 고양이 쪽으로 기어감 (속도 3, 고양이는 5) | 1.8칸 안 → 덮치기 / 10칸 이상 3초 → 복귀 |
| 덮치기 | 0.35초 동안 빠르게 튀어나감 | → 다시 추격 |
| 복귀 | 원래 자리로 천천히 돌아감 | 도착하면 → 숨어 있음 |

- 고양이 시야: 고양이가 바라보는 쪽 6칸 안 + 벽(Ground 레이어)에 가리지 않을 때만 보임. 1.5칸 안이면 등 뒤라도 보임. 안 보일 때는 서서히 투명해짐
- 추격 중에는 고양이가 등을 돌려도 계속 보이도록 설정 (`Stay Visible When Chasing`)
- 고양이가 턱 위(1.2칸 이상)에 있으면 덮치지 못하고 아래에서 대기
- 고양이 또는 주인과 닿으면 잡힘 로그 출력 (게임오버는 다음 작업)
- 충돌 상자 크기를 상태에 따라 자동 변경: 서 있을 때 0.9×1.8 / 기어갈 때 1.8×1.0
- 존재를 주인이 가는 길목(방2)에 배치 → 고양이가 존재를 유인해 길을 비켜야 주인이 지나갈 수 있음 (핵심 플레이)
- 존재 스프라이트 11개의 기준점도 발밑으로 변경, 고양이가 바라보는 방향(`Facing`)을 `CatController`에서 공개

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 충돌 상자가 서 있는 존재보다 낮아 상체 쪽으로 점프하면 잡히지 않음 | 서 있을 때와 기어갈 때 상자 크기를 따로 지정 |
| 존재가 아예 보이지 않음 | Cat·Owner 칸이 비어 있었음 → 비어 있으면 씬에서 자동으로 찾도록 수정 |
| 왼쪽으로 도망치면 존재가 사라져 긴장감이 떨어짐 | 추격 중에는 계속 보이도록 변경 |

**보완할 점 (나중에)**
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 고양이·주인을 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재에게서 도망치는 방법(숨기, 시야 밖으로 벗어나기 등)은 스토리를 구성하면서 다시 정하기
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
