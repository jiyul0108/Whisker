# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 (한 번도 죽지 않았을 때 기준) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께)
5. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀과 존재에게서 벗어나는 힌트를 얻음
6. **열쇠와 잠긴 방** — 열쇠를 찾아 잠긴 방을 열고 앞으로 나아감
7. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |
| S / ↓ | 숨을 곳에서 숨기 / 나오기 |
| W / ↑ | 쪽지 읽기 / 닫기 (Esc로도 닫기) |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 프로젝트 구조

```

├── Art/Backgrounds/              방 배경 (room01_bg: 1번 방)

│   ├── Cat/Sprites/              고양이 스프라이트 (모션별 폴더)
│   ├── Owner/Sprites/            주인 스프라이트 (idle, walk, hide)
│   └── Presence/Sprites/         존재 스프라이트 시안 (idle, notice, crawl, pounce)

├── Fonts/                        한글 폰트 (Galmuri11)
├── Physics/                      물리 재질 (NoFriction)
├── Scenes/Prototype/              Main 씬 (테스트 맵)
└── Scripts/
    ├── CatController.cs          고양이 이동·점프·바닥 체크
    ├── CatAnimator.cs            고양이 애니메이션 (대기·걷기·점프·착지·울기·숨기)
    ├── CatMeow.cs                울기 (주인 호출)
    ├── CameraFollow.cs           카메라 따라가기 (높이 고정, 방 범위 밖 안 보이게)
    ├── GameManager.cs            게임오버·암전·처음부터 재시작
    ├── HideController.cs         숨기·나오기 (고양이 혼자 / 주인과 함께)
    ├── HideSpot.cs               숨을 곳 (박스·책상 등)
    ├── Note.cs                   쪽지 (제목·내용, 읽음 표시)
    ├── NoteUI.cs                 쪽지 읽기 안내·팝업·모은 개수 표시
    ├── OwnerController.cs        주인 이동 (고양이 따라가기·멈추기·숨기, 벽·낭떠러지 감지)
    ├── OwnerAnimator.cs          주인 애니메이션 (대기·걷기·숨기) + 떨림
    └── PresenceAI.cs             존재 AI (시야 판정·발견·추격·덮치기·수색·복귀)
```

## 개발 기록

### 2026.11.03 (화) — 배경 방향 확정 + 1번 방 배경 적용

**스토리 변경**
- "고양이를 쫓아 들어감" 도입은 빼고, **처음부터 고양이와 주인이 폐건물에 갇힌 상태**로 시작
- 1번 방은 판자로 막힌 문과 창문이 있는 방 (돌아갈 수 없음), 오른쪽 출입구로만 나아감

**배경 방향 찾기 (Gemini)**
| 시도 | 결과 | 판단 |
| --- | --- | --- |
| 방 하나를 정면에서 본 그림 (양옆 벽이 비스듬함) | 분위기는 좋지만, 뒷벽에 붙은 문을 캐릭터가 지나가지 못하고 벽을 뚫고 가는 것처럼 보임 | 사용 안 함 |
| 단면도 구도 요청 | 원근이 남아서 단면도가 안 나옴 | 사용 안 함 |
| 벽 텍스처 / 바닥 띠 / 문틀을 따로 생성 | 벽·바닥은 평평하게 잘 나옴, 문틀은 비스듬함 | 방식은 참고 |
| **건축 입면도처럼 평평한 벽 + 높은 천장 + 나무판자 바닥** | 원근 없음, 캐릭터와 그림체·크기가 잘 맞음 | **확정** |

- 다른 공포 게임 장면을 참고해 "원근 없는 평평한 뒷벽 + 얇은 바닥 띠" 구도로 방향을 잡음
- 바닥은 나무판자 띠 위에 캐릭터를 세우고, 그 아래는 검은 공간 (안내 문구 자리로 활용)
- 천장을 높게(문이 벽 높이의 약 1/3) 요청해서 문 크기를 캐릭터에 맞춰도 배경이 화면을 꽉 채움
- 프롬프트 핵심 표현: "flat front elevation, like an architectural elevation drawing", "very high ceiling", "the door reaches only about one third of the wall height"

**1번 방 적용**
- 원본(3584×1184)에서 워터마크 부분을 잘라내고 절반 크기(1700×592)로 줄여 캐릭터 픽셀 크기와 맞춤
- 그림 기준점을 **왼쪽 끝 판자 윗선**에 맞춤 → 배경을 y = -2.5에 놓으면 판자 윗선 = 바닥 충돌체 윗면
- 출입구 기둥(`exit_pillar`)을 배경 색감에 맞춰 Python으로 제작, 캐릭터보다 앞(Order 20)에 배치 → 캐릭터가 지나가면 어두운 출입구 속으로 사라져 보임
- 예전 테스트 맵(칸막이, 턱, 천장 등)은 `OldMap`으로 묶어 꺼둠. 바닥·왼쪽 벽은 그림만 끄고 충돌체는 유지
- 카메라: Size 5 → **3** (문 크기가 주인 키의 약 1.35배가 되게), 배경색 검정
- `CameraFollow`: 높이 고정(`Lock Y`), 방 범위 밖이 화면에 안 보이게 제한(`Room Left / Right`), 방 이동 시 범위를 바꾸는 `SetRoomBounds()` 추가
- 고양이 Jump Force 20 → **11** (방 높이에 맞춰 약 2칸 점프)

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 첫 배경에서 오른쪽 문이 뒷벽에 붙어 있어 캐릭터가 벽을 통과하는 것처럼 보일 것 같음 | 원근 없는 평평한 벽 구도로 다시 생성하고, 출입구는 방 끝에 세운 기둥으로 처리 |
| 문 크기를 캐릭터에 맞추면 배경이 작아 보임 | 천장을 높게, 문을 벽 높이의 1/3로 다시 요청 |
| 카메라가 오른쪽 끝까지 안 가서 출입구가 안 보임 | Game 창의 Scale이 확대되어 화면 가장자리가 잘려 보였음 → Scale 1x, 비율 16:9로 변경 (게임 자체에는 영향 없음) |
| 쪽지가 공중에 떠 있음 | 예전 턱 위(y = -0.25)에 있었음 → y = -2.5로 이동. Play 중에 바꾼 값은 Play를 끄면 되돌아가므로 Play를 끈 상태에서 수정 후 저장 |

**보완할 점 (나중에)**
- 1번 방은 원래 존재가 없는 튜토리얼 방 → 존재, 박스 위치는 방 구성 확정 후 다시 배치
- 출입구 기둥이 단순함 → 필요하면 디테일 추가. 다음 방과 연결(방 이동) 기능 필요
- 고양이 크기: 주인 허벅지 높이까지 와서 조금 커 보임 → 필요하면 Visual Scale 0.8 정도로 조정
- 방 10개 구성 확정, 쪽지 내용 확정
- 열쇠·잠긴 문 기능 구현
- 나머지 방 배경 (같은 프롬프트에서 장면 설명만 바꿔 생성)
- 숨을 곳 그림(박스, 책상 등)과 쪽지 그림은 임시 → 배경 그림체에 맞춰 교체
- 숨기 밸런스: 존재 바로 앞에서도 숨을 수 있어 너무 쉬울 수 있음 → 방 제작 후 테스트하며 조정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
