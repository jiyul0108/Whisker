# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심, 조사·퍼즐) |
| 플레이 시간 | 1회 클리어 약 15분 목표 (1차 테스트: 5~10분 2명, 10~15분 1명, 20분 이상 1명) |
| 맵 | 폐병원 방 10개, 1층·지하·2층 (계단으로 이동) |
| 언어 | 영어(기본) / 한국어 — 설정에서 바꿈 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL, itch.io 공개 (Public, 11/10) — 1차 사용자 테스트 완료(11/13), 2차 예정 |
| 개발 | 1인 개발 |

## 맵 구성

```
 2층   [10 수술실][9 병실(어두움)][8 진료실 ⬇]
                                       ↕  (전자 잠금 철문: 전기가 들어오면 열림)
 1층   [1 시작][2 대기실][3 복도][4 계단실 ⬇ …소화기함… ⬆][5 로비·정문]
                                    ↕  (자물쇠 철문: 녹슨 열쇠)
 지하                          [6 지하 복도][7 창고]   ← 둘 다 어두움, 전기가 들어오면 밝아짐
```

| 진행 | 내용 |
| --- | --- |
| 0 | 1번 방: 바닥 안내 그림(이동·점프·울기·숨기·조사·가방)을 지나 E 안내 아래의 **주인**을 E로 부름. 숨기 안내 밑에 연습용 상자가 있음. 주인과 함께여야 2번 방으로 넘어갈 수 있고, 둘 다 넘어가면 문이 끼익 닫힘 |
| 1 | 3번 복도에 들어서면 존재가 뒷모습으로 서 있다가 다가가면 웃으며 사라짐 → 그 자리에 **쪽지** ("지하 창고 두꺼비집 퓨즈가 나갔다, 예비 퓨즈는 1층 대기실(의자와 책상이 있는 방) 벽시계 뒤") |
| 2 | 3번 복도 바닥의 **녹슨 열쇠**(반짝임) → 4번 계단실 지하 철문을 열고 지하로. 오른쪽 안쪽에서 두꺼비집이 지지직거리는 소리가 들림 |
| 3 | 7번 창고 **두꺼비집 작동하기** → 퓨즈가 빠져 있음 (이걸 확인해야 시계에서 퓨즈가 나오고, 이때부터 시계가 반짝임) |
| 4 | 2번 대기실 **의자**를 밀어 시계 밑에 놓고(의자는 2번 방 안에서만 밀림), 의자 위에서 **벽 타기** → **시계** 뒤에서 **퓨즈** |
| 5 | 두꺼비집에 퓨즈 끼우기 (게이지 6초, 그동안 존재가 새로 나타나지 않음) → "쿵" 전기가 들어옴 → 2층 철문이 열리는 장면 → 6초 뒤 **존재가 계단으로 내려와 창고부터 훑음**. 주인과 함께 7번 창고 상자 더미에 숨으면 숨은 곳 앞에서 노려보다 지나감 (숨는 걸 들키면 상자를 들춰서 잡음) |
| 6 | 5번 로비 안내데스크 **간호 일지** (침대 색 순서) + 9번 병실 **침대 4개** (이불 끝 꼬리표: 색 + 숫자) → 8번 진료실 **금고** 번호 **9472** → **열쇠 조각 (손잡이)** |
| 7 | 5번 로비 **화분** → **열쇠 조각 (끝)**, 4번 계단실 **소화기함** → **땜납** (순서 상관없음, 아이템이 있는 곳은 반짝임) |
| 8 | 10번 수술실 **수술대 → 열쇠 조각 붙이기**: 재료가 모자라면 모자란 아이템을 알려줌. 다 모으면 게이지 10초 → 출구 열쇠가 바닥에 떨어짐 |
| 9 | 열쇠를 줍고 문 쪽으로 가면 **존재가 천장에서 수술대 위로 떨어짐** → 숨을 곳 없이 끝까지 쫓아옴 |
| 10 | 1층 5번 로비 정문을 **주인과 함께** 열면 탈출 (정문은 지나갈 수 있음, 쫓기면 안내데스크 뒤에 숨을 수 있음) |

- 숨을 곳: 1번 연습 상자, 2번 박스·책상, 3번 책상, 5번 안내데스크, 7번 상자 더미, 8번 책상, 10번 수술대 (추격 중에는 숨을 수 없음)
- 방 규칙: **1번** 존재가 절대 들어오지 않음 / **2번** 갑자기 나타나지는 않지만 쫓아서 들어옴 / **지하(6·7번)** 갑자기 나타나지는 않지만 계단으로 쫓아 내려오고 숨은 곳도 찾아옴
- 깜짝 등장(쫓아오지 않는 연출): 3번 복도(쪽지 위), 지하 복도, 2층 진료실, 병실 — 처음 지나갈 때 한 번씩

## 핵심 기능

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 의자 위에서 벽 타기
2. **고양이 시야** — 맵 전체가 어둡고, 고양이 눈에서 바라보는 쪽으로 원뿔 모양 빛(URP 2D Light). 숨으면 원뿔이 꺼지고 둘레만 좁게 보임
3. **존재** — 주인은 인식하지 못하는 적. 평소엔 사라져 있다가 고양이가 있는 방에서 천천히 드러나 고양이가 있던 곳으로 기어옴. 같은 방에서 눈이 마주치면 비명을 지르고 쫓아오고(멀어지면 빨라져 화면 밖으로 놓치지 않음, 지하까지 따라옴), 숨으면 숨은 곳 바로 앞까지 와서 노려보다 사라짐. 쫓는 중에 보는 앞에서 숨으면 "숨는 걸 들켰다"가 뜨고, 숨은 곳을 들춰서 끌어냄. 계단을 타고 층을 넘나들고, 주인의 비명을 듣고 찾아옴. 고양이나 주인이 닿으면 게임오버
4. **주인 인도** — E(울기)로 주인이 고양이 자리까지 따라오게 하거나, 걷는 중에 멈추게 함. 존재가 쫓아오면 뛰어서 따라옴. 화면 가운데 위에 주인 상태(따라오는 중 / 기다리는 중 / 숨어 있음)
5. **주인 공포도** — 처음 E로 부르기 전에는 0. 고양이와 멀어지거나 어두운 방에 있으면 오르고, 높을수록 느려짐. 가득 차면 비명을 지르고 존재가 소리를 듣고 옴. 울면 조금 진정
6. **숨기** — 박스·책상 등에 주인과 함께 숨어 존재를 따돌림. 상자와 책상은 숨는 소리가 다름. 숨어 있으면 심장 소리가 더 빨라짐
7. **조사·퍼즐** — ↑로 물건 조사 (쪽지·문서, 침대 1인칭 확대, 금고 번호, 두꺼비집, 수술대). 시간이 걸리는 작업은 게이지 표시. 아이템이 숨겨진 곳은 별이 반짝임
8. **인벤토리·설정** — Tab으로 인벤토리, ← →로 설정(소리 크기·프레임 제한·FPS 표시·전체 화면·언어), Tab으로 닫기
9. **이벤트** — 전원 이벤트, 추격 이벤트, 깜짝 등장, 1→2번 방 문 닫힘
10. **사운드** — 배경음악, 쫓길 때 음악(이때는 배경음악이 꺼짐), 효과음 20여 개 (울음·발소리·비명·계단·기어다니는 소리·웃음소리·두꺼비집 지지직 등)
11. **타이틀·탈출·게임오버** — 타이틀(게임 시작 / 설정), 잡히면 이유(고양이·주인이 잡힘 / 숨는 걸 들킴)와 플레이 시간을 보여주고 처음부터 다시 시작(플레이 시간은 이어서 셈), 탈출 성공 화면(플레이 시간·잡힌 횟수)

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기, 주인 공포도 조금 내림) |
| ↑ | 조사하기, 계단 이용, 철문·정문 열기, 의자 위에서 벽 타기 |
| ↓ | 숨을 곳에서 숨기 / 나오기, 벽에서 내려오기 |
| Tab | 인벤토리 열기 / 닫기 (열린 상태에서 ← →로 설정과 오감) |
| Esc | 설정 열기 (웹 전체 화면에서는 전체 화면이 풀리면서 설정이 열림), 문서·침대·금고 창 닫기, 작업(게이지) 그만두기 |
| 설정 창 | ↑ ↓ 고르기, ← → 값 바꾸기 (맨 위 줄에서는 인벤토리로), Enter 선택, Tab 닫기 |
| 금고 | ← → 자리 이동, ↑ ↓ 숫자 바꾸기, 숫자 키로 바로 입력, Enter 확인 |
| R | 게임오버·탈출 화면에서 처음부터 다시 시작 |
| 타이틀 | ↑ ↓ + Enter 또는 마우스 클릭 (게임 시작 / 설정) |

    ├── GameInput.cs              조작을 막아야 하는 때 확인 (팝업·연출·계단 이동·게임 끝)

## 개발 기록

### 2026.11.13 (금) — 1차 사용자 테스트, 테스트 피드백 반영

**1차 사용자 테스트**
- 5명이 플레이(옆에서 실시간으로 지켜보며 의견 기록), 그중 4명이 설문 응답 (5문항: 이름, 플레이 시간, 난이도, 긴장감, 자유 의견)
- 결과: 난이도 평균 **3.0** / 5, 무섭고 긴장감 있었는지 평균 **3.5** / 5, 플레이 시간 5~10분 2명 · 10~15분 1명 · 20분 이상 1명
- 좋았던 점: 긴장감·재미, 고양이가 귀신을 보고 주인을 이끄는 설정이 참신함, 조작 설명이 이해하기 쉬움, 배경음악이 분위기에 맞음, 귀신이 리얼해서 무서움
- 평가 기준 공지 확인: 개발 완성도 10점 = 배포 완료 + **고객 10명 이상, 질문 10개 이상** 정량평가. 테스트 결과·고객 확보 내역은 기말고사 날 제출, 발표일(11/18)에는 상호평가만 → 1차는 5명·5문항이라 **2차 테스트(10명 이상, 10문항 이상)** 를 약 1주 뒤 진행

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 2번 방 박스에 숨을 때 새 소리가 안 남 | 그 박스는 씬에 원래 있던 오브젝트라 배치 메뉴가 소리를 연결하지 않았음 → 숨을 곳에 소리가 없으면 이름(박스·상자 / 그 외)으로 골라 주게 함 |
| 추격 음악이 너무 크고 배경음악과 겹침 | 파일을 약 7dB 줄이고, 쫓기는 동안엔 배경음악을 끄고 추격 음악만 나오게 함 |
| 숨는 소리가 너무 큼, 상자 소리가 어색함 | 상자 "속으로 들어가는" 소리 → 상자 더미 "뒤에 숨는" 소리로 다시 만들고, 두 소리를 약 10dB 줄임 |
| "웅웅거리는 기계 소리" 안내 문구가 어색함 | 문구를 없애고 두꺼비집 지지직 소리로 오른쪽을 알려줌 |
| 숨는 걸 들켜도 안내가 안 보여 버그처럼 느껴짐 | 아이템 메시지만 보이게 한 설정 때문에 "들켰다"가 숨겨져 있었음 → 노란 글씨로 보이게 함 |
