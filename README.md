# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 (한 번도 죽지 않았을 때 기준) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께)
5. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀과 존재에게서 벗어나는 힌트를 얻음
6. **열쇠와 잠긴 방** — 열쇠를 찾아 잠긴 방을 열고 앞으로 나아감
7. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |
| S / ↓ | 숨을 곳에서 숨기 / 나오기 |
| W / ↑ | 쪽지 읽기 / 닫기 (Esc로도 닫기) |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.11.02 (월) — 주인 이동 방식 변경 + 숨기 기능 + 스토리 방향 확정

**주인 이동 방식 변경 (웨이포인트 제거)**
- 정해진 지점(웨이포인트)을 순서대로 가던 방식 → 더 자유롭게 이끌 수 있도록 변경
- E로 울면 주인이 **고양이를 따라옴**. 운 뒤에 고양이가 움직여도 고양이의 지금 위치를 향해 계속 걸어옴
- 고양이 옆에 도착하면 멈춤 (다시 따라오게 하려면 또 울기). 걷는 중에 한 번 더 울면 그 자리에서 멈춤
- 주인이 울음소리를 듣는 거리를 4칸 → 10칸으로 늘림 (멀리서 불러야 하므로)
- 주인은 점프를 못 하므로 벽·낮은 천장·낭떠러지를 만나면 스스로 멈춤
  - 벽·천장: 몸 크기의 상자를 앞으로 밀어 부딪히는지 확인 (`BoxCast`)
  - 낭떠러지: 앞발 위치에서 아래로 바닥이 있는지 확인 (`Raycast`)
  - → 턱이나 좁은 통로는 고양이만 지나갈 수 있음

**숨기 기능**
- `HideSpot`: 숨을 곳(박스, 책상 등). 범위(Trigger) 안에 들어온 캐릭터를 확인
- `HideController`(고양이에 붙임): 숨을 곳 안에서 **S / ↓**로 숨기, 다시 누르면 나오기
  - 고양이만 안에 있으면 **고양이 혼자** 숨음 → "S / ↓ 박스에 숨기"
  - 주인도 같은 숨을 곳 안에 있으면 **둘 다** 숨음 → "S / ↓ 주인과 박스에 숨기"
  - 숨은 동안 숨기 그림 + 반투명, 고양이는 이동·점프·울기 불가
- 존재와의 관계
  - 숨은 쪽은 잡히지 않음
  - 쫓던 중 고양이가 숨으면 존재는 2.5초 동안 그 자리에서 두리번거리다(`Searching`) 원래 자리로 돌아감
  - 고양이 혼자 숨으면 **밖에 있는 주인은 잡힐 수 있음** (주인을 두고 혼자 숨는 건 위험한 선택)
  - 숨은 동안에도 고양이 눈에는 존재가 보임 (바로 앞을 지나가는 공포 연출)
- 숨기 안내 문구는 `NoteUI`에 추가한 두 번째 안내 줄(`SetExtraHint`)로 표시
- 숨기가 안 될 때 이유를 Console에 출력 (숨을 곳 없음, 공중에 있음, 범위 밖)
- 임시 나무 박스 그림 `box.png`를 Python으로 제작, 숨기 그림 4개(`cat_hide`, `owner_hide`)의 기준점을 발밑으로 변경

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 숨기가 안 됨 | 주인이 처음 위치에서 박스까지 너무 멀어 울음소리를 못 듣고 오지 못했음 → 중간에서 한 번 불러 가까이 데려온 뒤 다시 부르기. 실패 이유를 Console에 출력하도록 추가 |
| 주인이 운 순간의 위치까지만 오고, 그 뒤 고양이가 움직인 곳까지는 따라오지 않음 | 운 순간의 위치를 목표로 고정하지 않고, 걷는 동안 매번 고양이의 지금 위치로 목표를 갱신 |
| 주인 없이는 숨을 수 없어 답답함 | 고양이 혼자서도 숨을 수 있게 변경, 주인이 같이 있으면 함께 숨음 |
| 숨었을 때 고양이가 커 보임 | 숨기 그림 속 고양이가 다른 그림보다 약 1.25배 크게 그려져 있었음 → 숨기 그림 2장만 Pixels Per Unit 100 → 125로 변경해 80% 크기로 맞춤 (그림 크기를 맞추려고 **일부러** 다르게 둔 값) |

**스토리·기획 확정**
- 무대: **작은 폐병원**. 고양이가 먼저 깨진 창문으로 뛰어들고, 주인이 쫓아 들어감
- 처음에는 고양이도 주인도 그냥 폐건물로 생각함 → 쪽지를 모으면서 **폐병원이었다는 것**을 알게 됨
- 플레이 시간: 한 번도 죽지 않았을 때 기준 약 15분
- 방 개수: **10개 확정** (방별 구성은 아직 초안)
- 쪽지: 스토리 내용 + 각종 힌트 + 존재에게서 벗어나는 방법
- 새 요소: 들어갈 수 없는 방은 **열쇠**로 열기
- 배경 그림체: 어둡고 칙칙한 폐병원 느낌

**보완할 점 (나중에)**
- 방 10개 구성 확정, 쪽지 내용 확정
- 열쇠·잠긴 문 기능 구현
- 배경 이미지 (어둡고 칙칙한 폐병원, Gemini로 생성)
- 숨을 곳 그림(박스, 책상 등)과 쪽지 그림은 임시 → 배경 그림체에 맞춰 교체
- 숨기 밸런스: 존재 바로 앞에서도 숨을 수 있어 너무 쉬울 수 있음 → 방 제작 후 테스트하며 조정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
