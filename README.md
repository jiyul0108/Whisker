# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 이끌고 폐건물을 탈출하는 2D 사이드스크롤 공포 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 공포 (스토리 없이 탈출 중심) |
| 플레이 시간 | 1회 클리어 약 15분 (한 번도 죽지 않았을 때 기준, 방 10개) |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 주인은 인식하지 못하는 적. 존재 1명이 맵 전체를 알아서 돌아다니다가 고양이와 눈이 마주치면 쫓아옴 (항상 보이게 / 고양이 시야 안에서만 보이게 선택 가능)
3. **주인 인도** — '울기'로 주인이 고양이를 따라오게 하거나, 걷는 중에 멈추게 해서 안전한 길로 이끎
4. **숨기** — 박스·책상 등에 숨어 존재를 따돌림 (고양이 혼자 또는 주인과 함께, 맵 전체에 4곳)
5. **방 이동** — 출입구를 지나 다음 방으로. 고양이 혼자 먼저 갈 수도 있음
6. **열쇠와 잠긴 문** — 열쇠를 찾아 잠긴 문을 열고 앞으로 나아감 (고양이·주인은 막히고 존재는 통과)
7. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 조작법 (현재 프로토타입)

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프 |
| E | 울기 (주인이 고양이를 따라오게 하기 / 걷는 중이면 멈추기) |
| S / ↓ | 숨을 곳에서 숨기 / 나오기 |
| W / ↑ | 문 앞에서 문 열기 (맞는 열쇠가 있을 때) |
| R | 게임오버 화면에서 처음부터 다시 시작 |

## 개발 기록

### 2026.11.06 (금) — 존재가 맵을 알아서 돌아다니게 변경

**존재 이동 방식 변경**
- 순찰 지점을 일일이 넣지 않아도, 씬에 있는 방(Room)들 중에서 목적지를 골라 **알아서 계속 돌아다님**
  - 목적지에 도착하면 2초 멈췄다가 다음 목적지로 이동
  - 다음 목적지: 40% 확률로 같은 방의 다른 곳, 나머지는 다른 방 (`Stay In Room Chance`)
  - 방 끝에서 1칸 이상 떨어진 곳만 목적지로 고름 (`Roam Margin`)
  - **1번 방(시작 방)은 안전한 방**이라 목적지로 고르지 않음 (`Safe Room Names`에 Room 이름으로 지정)
  - 방 3~10을 추가하면 따로 설정하지 않아도 자동으로 돌아다닐 방에 포함됨
- 고양이를 놓치면 원래 자리로 돌아가지 않고 바로 다시 돌아다님
- 순찰 지점(Patrol Points)을 넣으면 예전처럼 그 지점들만 오감 (비워두면 자동)
- **항상 보이게** 옵션(`Always Visible`, 기본 켬): 고양이가 안 보고 있어도 존재가 사라지지 않음. 끄면 고양이 시야 안에서만 보임

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 순찰 지점을 방마다 직접 만들어 넣어야 해서 방을 늘릴 때마다 번거로움 | 씬의 Room 범위를 읽어서 목적지를 자동으로 고르게 함 |
| 존재가 고양이 시야 밖에서는 투명해져서 안 움직이는 것처럼 보임 | `Always Visible` 옵션 추가 |
| 방 범위(Room)가 준비되기 전에 목록을 읽을 수 있음 | 존재가 방 목록을 Awake가 아니라 Start에서 읽게 함 |

**보완할 점 (나중에)**
- **열쇠·잠긴 문·존재 자동 이동은 아직 테스트 전** → 1번→2번 방 문에 임시로 달아 테스트 (열쇠 없이 막힘, 열쇠 획득, 문 열기, 주인이 문 앞에서 멈춤, 존재가 2번 방을 계속 돌아다니는지)
- 항상 보이게 하면 "고양이만 볼 수 있다"는 연출이 약해짐 → 테스트 후 `Always Visible`을 유지할지 결정
- 존재가 맵 전체를 돌아다니므로, 주인을 존재가 다니는 길에 세워 두면 잡힘 → 긴장 요소로 둘지, 돌아다니는 중에는 주인을 못 잡게 할지 결정
- 맵이 길어지면 존재가 먼 방까지 가는 데 오래 걸림 → 이동 속도·대기 시간 조정
- 추격 중에는 1번 방(안전한 방)까지 쫓아올 수 있음 → 필요하면 막기
- 열쇠 크기가 작게 보일 수 있음 → Visual Scale 조정
- 방 3~10 배치 (구성표 초안: 11/05 커밋 기록 참고). 배경은 17칸 폭 기준 → 12~14칸 방은 기존 배경을 잘라 쓰고, 22~25칸 방은 넓은 배경 새로 생성
- 2번 방의 책상(숨을 곳)은 4번 방으로 이동 예정
- 탈출문 엔딩 연결 (`On Opened` → 엔딩 화면)
- 출입구 기둥이 단순함 → 필요하면 디테일 추가
- 발표용: 플레이 영상을 1~2분으로 편집, PPT 5장 구성, AI 활용에서 흥미로웠던 점 조사
- 고양이 크기: 주인 허벅지 높이까지 와서 조금 커 보임 → 필요하면 Visual Scale 0.8 정도로 조정
- 숨기 밸런스: 존재 바로 앞에서도 숨을 수 있어 너무 쉬울 수 있음 → 방 제작 후 테스트하며 조정
- 게임오버 문구를 한글로 변경 (Galmuri11 폰트 사용)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
