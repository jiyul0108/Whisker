# Whisker — 고양이만 볼 수 있는 것

> 폐건물에 갇힌 주인은 그곳을 떠도는 '존재'를 보지 못한다. 그것을 볼 수 있는 건 고양이뿐.
> 고양이가 되어 주인을 안전하게 탈출시키는 2D 사이드스크롤 내러티브 호러 게임.

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트

## 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 사이드스크롤 내러티브 호러 |
| 플레이 시간 | 1회 클리어 약 15분 |
| 엔진 | Unity 6.3 LTS (6000.3.26f1), Universal 2D (URP) |
| 배포 | WebGL (테스트 빌드 완료, 웹 배포 예정) |
| 개발 | 1인 개발 |

## 핵심 기능 (기획)

1. **고양이 이동 및 탐색** — 좌우 이동, 점프, 벽타기, 좁은 틈 통과
2. **존재 감지** — 고양이 시야 안에서만 보이는 적, 주인은 인식하지 못함
3. **주인 인도** — '울기'로 주인을 부르거나 멈추게 해서 안전한 길로 이끎
4. **스토리 쪽지 수집** — 방마다 숨겨진 쪽지로 건물의 비밀을 알아감
5. **게임오버 및 재시작** — 고양이 또는 주인이 존재와 닿으면 처음부터 다시 시작

## 프로젝트 구조

```
Assets/
├── Art/Characters/
│   ├── Cat/Sprites/              고양이 스프라이트 (모션별 폴더)
│   ├── Owner/Sprites/            주인 스프라이트 (idle, walk, hide)
│   └── Presence/Sprites/         존재 스프라이트 시안 (idle, notice, crawl, pounce)
├── Physics/                      물리 재질 (NoFriction)
├── Scenes/Prototype/              Main 씬 (테스트 맵)
└── Scripts/
    ├── CatController.cs          고양이 이동·점프·바닥 체크
    ├── CatAnimator.cs            고양이 애니메이션 (대기·걷기·점프·착지·울기)
    ├── CatMeow.cs                울기 (주인 호출)
    ├── CameraFollow.cs           카메라 따라가기
    ├── GameManager.cs            게임오버·암전·처음부터 재시작
    ├── OwnerController.cs        주인 웨이포인트 이동 상태 머신
    ├── OwnerAnimator.cs          주인 애니메이션 (대기·걷기) + 떨림
    └── PresenceAI.cs             존재 AI (시야 판정·발견·추격·덮치기·복귀)
```

## 개발 기록

### 2026.10.29 (목) — 게임오버·재시작 + WebGL 테스트 빌드

**게임오버 (`GameManager`)**
- 존재가 고양이 또는 주인과 닿으면 `PresenceAI`가 `GameManager.GameOver()` 호출
- 연출 순서: 0.6초 정지(잡힌 장면 보여주기) → 1초 동안 화면 암전 → "CAUGHT" + "Press R to restart" 표시
- R 키(또는 Enter)를 누르면 씬을 새로 불러와 처음부터 다시 시작 (체크포인트 없음)
- `Time.timeScale = 0`으로 모든 움직임을 멈추고, 연출은 실제 시간(`unscaledDeltaTime`) 기준으로 진행
- 게임오버 화면(검은 판, 글자)은 실행할 때 스크립트가 직접 생성 → 씬에 Canvas를 따로 만들 필요 없음
- `Auto Restart Delay`에 초를 넣으면 키 입력 없이 자동 재시작으로 바꿀 수 있음
- 숨어 있던(투명한) 존재가 주인을 잡아도 모습이 보이도록 잡는 순간 투명도를 1로 설정

**WebGL 테스트 빌드**
- Build Profiles의 Scene List를 SampleScene → `Scenes/Prototype/Main`으로 교체
- 플랫폼을 Web으로 전환 후 Build And Run → 브라우저에서 이동·점프·울기·존재 추격·게임오버·재시작 모두 정상 동작 확인
- 빌드 결과물은 프로젝트 폴더 밖(`Z:\Unity\Builds\Whisker_Web`)에 저장해 GitHub에 올라가지 않게 함

**문제 & 해결**
| 문제 | 해결 |
| --- | --- |
| 빌드 목록에 Main 씬이 없고 예전 SampleScene만 있음 (재시작 시 씬을 불러오지 못함) | Scene List에서 SampleScene 해제, Main 추가 |
| Unity 기본 폰트에 한글이 없어 WebGL에서 한글이 깨짐 | 게임오버 글자는 일단 영어로 표시, 한글 폰트는 UI 작업 때 추가 |

**보완할 점 (나중에)**
- 한글 폰트 추가 후 게임오버 문구를 한글로 변경 (UI 작업 때)
- 주인 에셋: 겁먹은 느낌이 부족함. 대기 ↔ 이동 전환이 자연스럽지 않음 (걷기 모션 자체는 괜찮음)
- 존재가 잡을 때 모션이 아쉬움 → Gemini로 붙잡는 동작 그림을 새로 생성해 교체
- 존재에게서 도망치는 방법(숨기, 시야 밖으로 벗어나기 등)은 스토리를 구성하면서 다시 정하기
- 존재 디자인은 아직 시안 (게임 안에서 더 테스트 후 확정)
